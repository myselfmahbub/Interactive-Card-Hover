# Interactive-Card-Hover

A simple and interactive **Card Hover Effect** project built using **HTML and CSS**.

This project was created as a practice project to learn and improve frontend fundamentals, especially **card layouts, hover effects, positioning, and CSS styling**.

## ✨ Features

* 🎴 Interactive card layout
* 🖱️ Smooth hover effects
* 🖼️ Pokémon-themed card images
* 📱 Simple and clean UI
* 💻 Beginner-friendly HTML & CSS project

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📂 Project Structure

```text
Interactive-Card-Hover/
│
├── index.html
├── style.css
└── README.md
```

## 🎯 Purpose

The main purpose of this project is to practice **HTML and CSS** by creating an interactive card-based interface and experimenting with hover effects and positioning.

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/myselfmahbub/Interactive-Card-Hover.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

## 📸 Preview

The project contains multiple Pokémon-themed cards arranged in an interactive card layout.
